# 글로벌 NPU 가이드

글로벌 NPU(NC Player Unit) 통합 체계에 대한 종합 가이드입니다.

## 📋 개요

기존 NCK 기준 NPU 체계에서 **NCK·NCA·NCT·NCJ 전 권역을 통합**한 글로벌 NPU로 진화하면서 달라진 기술 스펙, 데이터 구조, 지표 정의를 한눈에 파악할 수 있도록 정리한 문서입니다.

### 글로벌 NPU 도입 목표

1. **글로벌 사용자 단위 통합 체계 구축**
   - 권역별로 분산된 계정·인증 데이터를 통합
   - 전 세계 모든 서비스를 하나의 사용자 단위(Global NPU Key)로 식별

2. **표준화된 글로벌 KPI Framework 확립**
   - 권역·게임별 상이한 지표 정의를 통일
   - 글로벌 단위 일관된 KPI 비교 분석 구조 구축

3. **글로벌 유저 행동 기반의 고도화된 분석 환경 제공**
   - 통합 로그 기반 Retention, Funnel, Cannibalization 등 심화 분석 가능

## 📑 가이드 구성

### 1. **개요 탭**
기존 NPU와 글로벌 NPU의 주요 변경사항을 한눈에 비교합니다.

- ✅ 기존 NPU vs 글로벌 NPU 비교표
- ✅ 글로벌 NPU의 원천 — 통합 인증 체계
- ✅ **저장 포맷 비교보기** (Parquet vs Apache Iceberg format-version=2)

### 2. **데이터 적재 구조 탭**
매일 일별(D-1) 기준으로 처리되는 배치 프로세스를 시각화합니다.

- ✅ 글로벌 NPU 테이블 설계 개요 (10개 정규 테이블 + 3개 임시 테이블)
- ✅ 일별 배치 실행 순서 (13단계 파이프라인)
- ✅ 임시 테이블(Temporary Tables) 상세 설명

### 3. **테이블 정보 탭**
da_npu 스키마의 테이블 관계도와 매핑 정보를 제공합니다.

- ✅ ERD(Entity Relationship Diagram) — 10개 테이블 관계도
- ✅ 필드 상세 보기 (접이식)
- ✅ 기존 NPU → 글로벌 NPU 테이블 매핑
- ✅ 1:1 매핑, 통합(merge), 분리(split), 조건 추출 관계 표시

### 4. **제공 서비스 탭**
글로벌 NPU에서 확인 가능한 게임/서비스 목록입니다.

- ✅ **확인 가능 서비스(IP·계정) 목록** — 검색 기능 포함
  - 서비스명, svc_cd, app_group_cd로 검색 가능
  - 서비스명 기준 가나다순 정렬
- ✅ 게임 장르별 구분 (MMORPG, 슈팅, 스포츠 등)

### 5. **예시 쿼리 탭**
실전에서 바로 사용 가능한 추출 쿼리 4가지를 제공합니다.

- ✅ **게임별**: 일별 접속 NPU 수 · 총 플레이타임
- ✅ **권역별**: 결제 NPU 수 · 매출 (VAT 포함/제외)
- ✅ **국가별**: 접속 NPU 수
- ✅ **게임 × 국가**: 특정 게임의 국가별 매출 · ARPPU
- ✅ **장르별**: 접속 NPU 수

## 🎨 주요 특징

### 🔍 인터랙티브 인터페이스
- **5개 탭 구성**: 개요 → 데이터 적재 구조 → 테이블 정보 → 제공 서비스 → 예시 쿼리
- **검색 기능**: 제공 서비스 목록에서 실시간 필터링
- **비교보기 팝업**: 저장 포맷 상세 비교 (Format-Version 1 vs 2)

### 📊 상세한 다이어그램
- **일별 배치 실행 순서**: 13단계 파이프라인 플로우차트
  - 디멘전(파란색), 팩트(회색-초록색), 임시테이블(틸색) 색상 구분
  - 누적 참조 관계 표시

- **테이블 관계도(ERD)**: 10개 테이블의 관계를 직관적으로 표시
  - 직접 조인 관계 (실선)
  - 자기참조/누적 이력 참조 (점선)

- **기존 → 글로벌 매핑**: 테이블 매핑 관계 시각화
  - 1:1 매핑, 통합, 분리, 조건 추출 구분

## 📌 주요 변경사항 요약

| 항목 | 기존 NPU | 글로벌 NPU |
|------|---------|----------|
| 기준 권역 | NCK 기준 | NCK·NCA·NCT·NCJ 전 권역 통합 |
| 적재 DB | `da` | **`da_npu`** |
| 저장 포맷 | Parquet | **Apache Iceberg (format-version=2)** |
| 적재 범위 | NCK 일부 게임 | **전 권역 · 전 게임** |
| NPU Key 기준 | 전화번호 → SSN → NP 계정 | **전화번호 → 이메일 → NP 계정** |
| 매출 집계 | 부가세 포함만 | **부가세 포함/제외 모두** |
| 적재 주기 | D-1, D-14, D-30, D-60, D-90, D-365 | **D-1 (모든 테이블)** |

## 📐 기술 스펙

### 저장 포맷: Apache Iceberg format-version=2

**글로벌 NPU가 V2를 선택한 이유:**

1. **다중 권역에서 빈번한 스키마 변경 필요**
   - 기존 데이터와 호환성 유지하며 새 컬럼 추가 가능

2. **대규모 데이터의 삭제/업데이트 작업 효율화**
   - Position Delete 파일로 삭제 연산 성능 대폭 향상

3. **장기적인 데이터 관리 안정성**
   - ACID 트랜잭션 보장
   - 별도 메타스토어로 안정적 버전 추적

4. **멀티 권역 동시 처리**
   - 대규모 데이터 동시 접근 시 데이터 일관성 보장
